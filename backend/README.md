> AI-powered API to predict **Parkinson's Disease** from **voice biomarkers** using **SVC (Support Vector Classifier)**

---

## ✨ Features

- 🚀 FastAPI backend for ML-powered predictions  
- 🧪 Predict Parkinson’s from **22 voice features**  
- 🔒 Input validation with **Pydantic**  
- 💾 Model persistence using **joblib**  
- 🌐 CORS enabled for frontend integration  
- ⚡ Easy to replace synthetic data with **real dataset**

---

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI  
- **Machine Learning:** scikit-learn (SVC), StandardScaler  
- **Data Validation:** Pydantic  
- **Model Storage:** joblib
